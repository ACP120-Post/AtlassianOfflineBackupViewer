# Contributing

The viewer source, including SAML SSO, user import, per-user permission management, and the license-key verifier, is licensed under AGPL-3.0-only. The internal Forge license issuer is kept in the private development repository and excluded from this public repository.

Please open an issue before substantial work and send focused changes as pull requests. We ask commercial users especially to contribute generally useful changes upstream. This is a project request, not an AGPL obligation: AGPL requires source availability to users of modified network versions, but does not require changes to be submitted upstream. There is no CLA or rights-assignment requirement.

Do not commit backup archives, identity exports, local `settings.json`, credentials, private signing keys, or generated build output to the public repository. The official build gates SSO and other licensed features on a valid Marketplace license. Product support is available only with an active paid license; see [LICENSING.md](LICENSING.md).
